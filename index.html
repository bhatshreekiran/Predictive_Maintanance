📖 Demo Guide ▼
①
Simulator — Click ▶ Start. Watch VIB / TEMP / CUR charts scroll live.
②
Anomaly flag — Toggle "Force anom:1". All gauges turn red, alerts fill, chart points appear red. Toggle off to return to green.
③
Manual — Switch to Manual tab. Set sliders, enable Anomaly flag, type a reason code (e.g. VIB_HI), click Send Reading.
④
Drop & Reconnect — Click 📵 Drop Conn. Keep simulator running ~10 s. Watch queue badge count up. Click 🔄 Reconnect — all readings flush in order with correct timestamps (not bunched).
⑤
Replay — Export a CSV, drag it into Replay tab. Enable "New session", set 10×, click Play.
⑥
WebSocket — Run python bridge.py + python fake_device.py. Enter ws://localhost:8765, click Connect. Close browser, wait 30 s, reopen — all readings load from bridge JSONL.
⑦
Share & Export — Click 🔗 for QR code + URL. Click 🖨️ for a printable report. Export CSV / JSON for offline analysis.
